# RobotSoccer

![Visão 3D do RobotSoccer](docs/RobotSoccer_3D.jpg)

Projeto de um robô de futebol omnidirecional com chassi hexagonal, três motores N20 e três rodas omni distribuídas a 120°, mecanismo frontal de chute e peças projetadas para fabricação em PLA.

## Modelagem 3D

Os recursos paramétricos do Onshape estão consolidados em:

`3D/Onshape/RobotSoccer_All.fs`

## Arquitetura inicial

- Chassi hexagonal
- 3 motores N20 com encoder
- 3 rodas omni a 120°
- Abertura frontal para condução da bola
- Mecanismo de chute central
- Compartimento para bateria
- Plataforma para eletrônica de controle
